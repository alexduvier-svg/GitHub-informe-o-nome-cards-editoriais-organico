# Cards Editoriais Orgânicos — Skill compartilhada

Biblioteca de design de cards e carrosséis para GPT/Codex e Claude Code, inspirada na linguagem gráfica de uma publicação sobre turismo. Aplicar princípios de composição, sem copiar marcas, ilustrações ou textos de terceiros.

## Como usar

**Codex / GPT:** `Use $cards-editoriais-organicos para criar cinco cards sobre [tema], em Feed e Stories.`

**Claude Code:** `Use /cards-editoriais-organicos para criar cinco cards sobre [tema], em Feed e Stories.`

## Estilo

Fundo creme `#FFF8EB`, verde-floresta `#113A23`, terracota `#B84113`, mostarda `#F5B61B`, verde-sálvia `#E4E8BE`, tipografia sem serifa forte, caixas arredondadas, ilustrações flat e ondas orgânicas inferiores.

**Formatos:** Feed 1080×1350 (4:5) e Stories 1080×1920 (9:16), com redistribuição verdadeira.

## Acesso entre ferramentas

Um repositório GitHub público não instala automaticamente a skill nas conversas do ChatGPT ou Claude no navegador. Para Codex/Claude Code, abra ou clone o repositório como projeto. Em outros projetos, copie as respectivas pastas de skill ou forneça acesso ao repositório.
